パスのスラッシュ・バックスラッシュ変換

パス内の / と \（¥）を、どちらか一方にまとめて変換します。Windows と Mac・Linux のパスの書き換えに。

揃える区切り文字

入力したパスはこのページの中だけで変換され、どこにも送信されません。https:// などの URL はそのまま残します。

使い方

  1. 変換したいパスを入力欄に貼り付けます。複数行もまとめて変換できます。
  2. 「揃える区切り文字」で / か \ を選びます。入力に多い方と逆の区切り文字が自動で選ばれます。
  3. 「結果をコピー」を押します。入力欄で Ctrl + Enter を押してもコピーできます。

変換の例

Windows のパスを Mac・Linux 用に
C:\Users\Name\Documents
C:/Users/Name/Documents
Mac・Linux のパスを Windows 用に
/usr/local/bin
\usr\local\bin
区切り文字が混ざったパスを統一
src\components/Button.tsx
src/components/Button.tsx
円マーク（¥・￥）で書かれたパス
D:¥資料¥2026¥見積書.xlsx
D:/資料/2026/見積書.xlsx
URL はそのまま
a\b.md https://example.com
a/b.md https://example.com

よくある質問

なぜ \ が ¥ と表示されるのですか？

日本語の古い文字コード（JIS X 0201）では、英語圏でバックスラッシュがある位置に円記号が割り当てられていました。そのため多くの日本語フォントは、同じ文字を ¥ の形で表示します。見た目が違うだけで、Windows のパスではどちらも同じ区切り文字です。

全角の ￥ や ＼ も変換できますか？

できます。半角の \ と同じ区切り文字として扱い、選んだ方に変換します。全角の ／ も / として扱います。

ネットワークパス（\\server\share）も変換できますか？

できます。先頭の \\ も含めて変換され、/ を選ぶと //server/share になります。

入力したパスは送信されますか？

送信されません。変換はすべてお使いのブラウザの中で行われます。
