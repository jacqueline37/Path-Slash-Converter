Path Slash Converter
日本語 English

Convert slashes and backslashes in file paths

Make every separator in a path the same, all / or all \. Useful when moving paths between Windows, Mac and Linux.

Separator to use

Paths are converted on this page and never sent anywhere. URLs such as https:// are left as they are.

How to use it

  1. Paste a path into the input. Several lines are converted at once.
  2. Under “Separator to use”, pick / or \. The opposite of what your path mostly uses is picked for you.
  3. Select “Copy result”, or press Ctrl + Enter in the input.

Examples

Windows path to Mac or Linux
C:\Users\Name\Documents
C:/Users/Name/Documents
Mac or Linux path to Windows
/usr/local/bin
\usr\local\bin
Mixed separators
src\components/Button.tsx
src/components/Button.tsx
URLs are left alone
a\b.md https://example.com
a/b.md https://example.com

Questions

Why does \ sometimes look like ¥?

In the old Japanese character set JIS X 0201, the yen sign sits where ASCII has the backslash, so many Japanese fonts draw that character as ¥. It is the same character, and Windows treats both as a path separator. This tool converts ¥, fullwidth ￥ and ＼ as backslashes too.

Does it handle network paths like \\server\share?

Yes. The leading \\ is converted too, so picking / gives //server/share.

Is my path sent anywhere?

No. Everything runs in your browser.
