# Path Slash Converter

パス文字列内の `/`（スラッシュ）と `\`（バックスラッシュ）を、どちらか一方に揃えるツールです。
`¥` / `￥` / `＼` といった円記号・全角の表記も `\` として認識します。

https://jacqueline37.github.io/Path-Slash-Converter/

## できること

- 貼り付けた瞬間に変換（ボタンを押す必要はありません）
- `/` に揃える・`\` に揃えるを選択。入力に多い方と逆の区切り文字が自動で選ばれます
- `/` と `\` が混ざったパスも、どちらか一方にきれいに統一
- 変えた区切り文字を赤ペンのように色付きで表示
- `https://` などの URL はそのまま残す
- 変換結果をワンクリックでコピー（入力欄で `Ctrl` + `Enter` でもコピー）
- 日本語 / English の切り替え（`?lang=en` で英語表示）
- 端末のダーク / ライトモード設定に自動対応
- 入力したパスはブラウザの中だけで処理され、どこにも送信されません

## 使い方

1. 入力欄にパスを貼り付ける（例: `C:\Users\Name\Documents\file.txt`）
2. 必要なら「揃える区切り文字」で `/` か `\` を選ぶ
3. 「結果をコピー」を押す
