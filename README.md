# Path Slash Converter

パス文字列内の `/`（スラッシュ）と `\`（バックスラッシュ）を相互変換できるツールです。
`¥` / `￥` / `＼` といった全角・半角の円記号表記も自動的に `\` として認識して変換します。

## できること

- `/` ⇄ `\` をワンクリックで相互変換
- `¥` / `￥` / `＼` も `\` として自動認識
- 変換結果をワンクリックでコピー
- 入力・出力をワンクリックでクリア
- 日本語 / English の切り替え
- 端末のダーク / ライトモード設定に自動対応
- スマートフォンでも使いやすいレイアウト

## 使い方

1. ページを開く
2. 入力欄にパス文字列を貼り付ける（例: `C:\Users\Name\Documents\file.txt`）
3. `/ ⇄ \ (¥)` ボタンを押すと、変換結果が下の欄に表示される
4. `Copy` ボタンで変換結果をコピーできる
