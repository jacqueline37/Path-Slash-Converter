# Path Slash Converter

パス文字列内の `/`（スラッシュ）と `\`（バックスラッシュ）を相互変換するシンプルなブラウザツールです。
`¥` / `￥` / `＼` といった全角・半角の円記号表記も `\` として自動的に正規化してから変換します。

## 主な機能

- `/` ⇄ `\` のワンクリック相互変換
- `¥` / `￥` / `＼` を `\` として自動認識
- 変換結果をワンクリックでクリップボードにコピー
- 入力・出力のクリア
- 日本語 / English の切り替え（`?lang=ja` / `?lang=en` の URL パラメータ、およびブラウザへの設定保存に対応）
- OS のライト / ダークモード設定に自動追従
- スマートフォンなどの狭い画面にも対応したレスポンシブレイアウト

## 使い方

1. `index.html` をブラウザで開く
2. 入力欄にパス文字列を貼り付ける（例: `C:\Users\Name\Documents\file.txt`）
3. `/ ⇄ \ (¥)` ボタンを押すと、変換結果が出力欄に表示される
4. `Copy` ボタンで変換結果をコピー、`Clear` ボタンで入力・出力をクリア

## 技術構成

ビルド不要の素の HTML / CSS / JavaScript のみで構成されています。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面構成 |
| `style.css` | スタイル（ライト / ダークテーマ対応） |
| `script.js` | 変換ロジック・多言語対応 |

## ローカルでの実行

ビルド手順は不要です。リポジトリをクローンして `index.html` をブラウザで直接開くだけで動作します。

```bash
git clone https://github.com/jacqueline37/Path-Slash-Converter.git
cd Path-Slash-Converter
```
